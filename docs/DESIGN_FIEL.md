# Design recuperado da versão do Henrique

A aplicação principal deste pacote usa o `bundle.js` capturado da versão recente.
Por isso, o frontend executado preserva o visual observado no preview, inclusive:

- paleta: midnight `#0A1128`, emerald `#059669`, blue `#2563EB`
- fundo `#FAFAFA`
- superfície branca `#FFFFFF`
- borda `#E5E7EB`
- texto principal `#111827`
- texto secundário `#4B5563`
- alerta `#DC2626`
- aviso `#D97706`
- tipografia prevista no bundle: Outfit + IBM Plex Sans + IBM Plex Mono
- cards com raio de 6px
- sidebar escura
- Dashboard com 4 KPIs, gráfico, Radar Inteligente e alertas
- rotas: landing, login, cadastro, dashboard, vendas, estoque, clientes,
  financeiro e configurações
- drawer lateral "Falar com IA"

IMPORTANTE:
Este visual é preservado pelo bundle compilado recuperado. Ele é mais fiel ao
preview do Henrique do que a versão React limpa, que continua sendo uma
reconstrução editável e não o código-fonte original caractere por caractere.
